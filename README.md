# Violon cadien, jour après jour

Application web gratuite pour apprendre le violon cadien, un exercice par jour, avec le violon accordé un ton plus bas (Fa-Do-Sol-Ré) pour jouer avec un accordéon en Do. Français et anglais.

Free web app for learning Cadien (Cajun) fiddle, one exercise a day, with the fiddle tuned down a whole step (F-C-G-D) to play with a C accordion. French and English.

## Développement

```sh
npm install
npm run dev     # serveur local
npm test        # tests de la théorie musicale et du contenu
npm run build   # version de production dans dist/
```

Le site est publié automatiquement sur GitHub Pages à chaque envoi sur `main` (voir `.github/workflows/deploy.yml`).

## Contenu

Les exercices et les mélodies sont originaux. Le vocabulaire du seconding s'inspire du livret de Dewey Balfa et Tracy Schwarz, *Traditional Cajun Fiddle* (Smithsonian Folkways, 1976) ; aucun texte, diagramme ni arrangement du livret n'est reproduit.
